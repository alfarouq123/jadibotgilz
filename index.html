📘 Panduan Install
Cara menjalankan GilzzzBotzz di VPS / RDP / Replit / laptopmu sendiri.

Persyaratan

✅ Web dashboard INI nyambung ke bot. Jalankan bot dengan Node di server/VPS, lalu buka http://IP-VPS-kamu:3000 — QR / pairing code / setting / log di web bakal REAL TIME.
1
Node.js 22+Bot butuh Node >= 22. Cek: node -v
2
Upload source bot ke VPSPake git / scp / FileZilla. Pastikan folder public/ dan src/dashboard-server.js ada.
3
Install dependenciesDi folder bot ketik npm install lalu enter.
4
Jalankan botKetik npm start. Dashboard web otomatis nyala di port 3000. Buka di browser, masuk ke menu Tautkan Perangkat.
5
PairingMasukin nomor WA kamu (format 62xxx) → klik Minta Kode → buka WA di HP → Perangkat Tertaut → Tautkan pake nomor → masukin kode 8 huruf. Selesai.
6
Daftarin OwnerSetelah terhubung, buka menu Owner Bot dan masukin nomor owner yang bisa kontrol penuh.
7
(Opsional) Biar 24/7Pake pm2: npm i -g pm2 && pm2 start index.js --name gilzzzbotzz && pm2 save
💬 Minta bantuan install📂 Repo GitHub
💡 Tidak pakai Pterodactyl — Pterodactyl itu panel buat game server (Minecraft, CS, dll). Bot WhatsApp jalan cuma dengan Node.js biasa (VPS, RDP, Railway, Render, Replit, bahkan laptopmu dirumah).
